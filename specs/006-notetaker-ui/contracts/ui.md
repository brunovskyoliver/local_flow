# UI contract

Notetaker opens the saved recordings list. New note starts recording with the configured transcription choice. Hover or focus previews without selecting. A row click opens My thoughts. Back flushes notes and returns to the list. Tabs preserve the editor and change the reading content only. Previous/next buttons navigate within the loaded notes after flushing thoughts; buttons at the bounds are disabled. Title writes stay attached to the edited recording even if navigation happens before saving starts.

Copy link, Share and Report explain unavailable services. Delete confirms before using the existing revision-checked deletion path. Recording details exposes playback, metadata, failures and recovery. Summary and Ask anything explain unavailable services. Resume is available only for an actually paused active recording.

Source labels: mic = You, system = Others, both = Unassigned. Labels describe audio sources and make no diarization claim.
