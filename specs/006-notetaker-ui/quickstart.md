# Validation

1. Run `make check`.
2. Open Notetaker. Inspect empty state and New note/transcription controls.
3. With synthetic saved recordings, hover/focus rows and open the ellipsis menu. Confirm date grouping, right preview and Delete confirmation.
4. Open a note, edit My thoughts, switch tabs, return and reopen. Confirm saved text.
5. Inspect transcript bubbles for all three source values, paging/copy and recording-details playback.
6. Inspect summary/shared-note/chat unavailable states. Resize to compact and inspect dark appearance.

Screenshots must use synthetic records. Hardware capture and memory acceptance are separate.
