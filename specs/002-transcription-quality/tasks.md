## Implementation strategy

1. Deliver the US1 evaluation MVP first: private evidence, preserved v1 baseline, v2 failure-accounting runner/scorer and a truthful baseline report. Authentic corpus acquisition can remain explicitly open while deterministic tooling is validated.
2. Deliver US2 with exact raw preservation, conservative joins, atomic full-envelope storage and existing recovery safeguards. Replay saved evidence before rerunning inference.
3. Deliver US3 with empty vocabulary first, then US4's persistent vocabulary and editor. This isolates formatting from spelling replacement and keeps history immutable.
4. Perform controlled experiments and real offline/resource acceptance. Retain Parakeet unless measured evidence supports a separate adoption decision; this list does not silently add production fallback scope.
5. Run the repository's analysis step before implementation. Keep tasks involving missing licensed recordings, human verdicts or M5/signed-app measurements unchecked until the actual evidence exists.
